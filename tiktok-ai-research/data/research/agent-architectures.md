# Agent architectures: what to consider

Theme: agent-architectures. 14 liked videos (7 creators selling "Jarvis"/"AI company" setups, 1 on-call-engineer loop, 1 handoff pattern, 1 decision-model demo, 1 multi-model framing). Researched 2026-10-10. Star counts and commit dates are from the GitHub API on that day; Anthropic facts are from code.claude.com, platform.claude.com and support.claude.com pages fetched the same day. Vendor sites for TypeSafe, OpenAI, Trillion and Cursor were unreachable from the research sandbox, so those rows rest on consistent secondary coverage and are marked as such in the JSON. The companion file `agent-architectures.json` has 29 verdict rows.

## What the creators are collectively saying (patterns, not individual videos)

1. **"Build your own Jarvis" is the dominant pitch, and it is a funnel.** Five of the 14 videos (luke.builds.ai x2, taki.gpt, ethanplusai, chase_ai_) describe the same layer cake: a home (VPS/Mac mini), a harness (Hermes), a swappable model, business context, memory, skills, tool connections, chat/voice channels, a dashboard. Three of them end in "comment Jarvis" for an email course or a $98/month Skool community. None show a working system end to end. The architecture is fine; it is also exactly the architecture Claude Code already ships (skills, CLAUDE.md memory, MCP connectors, Routines, Desktop scheduled tasks, Projects).

2. **"Turn Claude into a company" (org charts, heartbeats, budgets).** Paperclip (99.5k stars), the Cowork four-agent team, and Automaton (agents with wallets that "die") all sell hierarchy as leverage. The creator credentials ("Stanford founder, raised $4M") repeat across bengusberg's three videos and are about him, not the tool.

3. **Cheap decider in front of the expensive model.** Two videos (adamstewartmarketing, chase_ai_) wire TypeSafe's Jev as a sub-second classifier that routes every request into tiers before Codex/Claude Code does the work. OpenAI shipped the same category (Decisions API) on 2026-10-06. The idea is sound; the specific vendor is optional.

4. **Autonomous bug-fixing while you sleep.** youraveragetechbro's loop (PostHog error -> cloud agent reproduces -> fixes -> verifies with skills -> risk-gated merge -> two other models review) is the one video with a real production system behind it (his startup Yorby).

5. **Handoff hygiene.** kevinfremon's WWWHH note (Why ready / What next / Where the files are / Heads up / How sure) is the only pure engineering idea in the set: paths instead of contents, a confidence number the orchestrator can gate on.

6. **Multi-model as status.** nocode.joshua's route/chain/council ladder ("top 1% use a council") and the on-call video's "three models must agree" both treat more models as more safety. Model names on screen (Grok 4.7, GPT 6.1) are partly unverifiable.

## What holds up vs what is hype (with evidence)

**Holds up**

- **Hermes Agent exists and is huge**: NousResearch/hermes-agent, 252,449 stars, pushed 2026-10-10, MIT. It also carries 47,752 open issues and two 2026 injection CVEs (CVE-2026-9353, CVE-2026-9366). Its "Anthropic OAuth" provider borrows Claude Code credentials and "routes as Claude Code"; the docs say it "only works if you're on a Claude Max plan and have purchased extra usage credits" and Pro users cannot use it. That is the harness pattern Anthropic blocked from subscription allowances on 2026-04-04.
- **ethanplusai/jarvis exists**: 847 stars, last push 2026-09-10, macOS + Chrome + Fish Audio only (not ElevenLabs), license is personal/non-commercial, builds run `claude -p --dangerously-skip-permissions` by default. The "no API key, runs on Max" claim is true because it drives the unmodified Claude Code binary under the user's own login, which Anthropic's legal page explicitly permits. "Orcha" is a window on his monitor; no such project is public.
- **Paperclip's "90k stars" was true** (99,514 today), MIT, active. Its Claude adapter runs Claude Code headless with `dangerouslySkipPermissions` defaulting to true. No independent cost or security review exists; 6,330 open issues after seven months.
- **gstack is real and maintained**: 135,800 stars, pushed 2026-10-09, MIT, 23 skills (the video's "30 employees" is inflated; "129,000 downloads" was the star count then). "Learns from its bugs" is a `/learn` notes file that compounds across sessions. `/design` calls OpenAI gpt-5.5 by default. Telemetry opt-in, default off.
- **12-factor agents**: 26,637 stars, Apache/CC BY-SA, last commit 2025-09-21. A principles doc; its advice matches Anthropic's own.
- **Jev**: early access since 2026-09-15, $0.042 per 1M input tokens, output unbilled; vendor claims 70-500 ms, a reseller measured 0.84 s end to end. A reseller benchmark shows Opus 5.5 and GPT-6 Sol beating it by ~7 points on 77-intent routing; cheap LLMs tied it. No calibration study. The MCP tool in the video was generated by Codex, not shipped by TypeSafe.
- **OpenAI Decisions API**: public beta 2026-10-06 on GPT-6 Luna, `/v1/decisions`, predicates/choices/scores; pricing reported as $0.10 per 1M input by one source and "unpublished" by another.
- **The on-call loop is buildable natively**: Claude Code Routines (research preview, Pro/Max/Team/Enterprise) have an API trigger (`POST .../routines/{id}/fire` with a bearer token and free-text payload) and GitHub triggers on `pull_request`/`release`; the official doc's own example is "Alert triage: your monitoring tool calls the routine's API endpoint ... opens a draft pull request with a proposed fix." PostHog error-tracking alerts post to an HTTP webhook on new/reopened issues. Projects' cloud threads open PRs and auto-fix failing CI.
- **Zernio MCP** (the "Zernio MCP" heard in the metrics video) is real: mcp.zernio.com, 280+ tools over 15-16 networks, first two connected accounts free. **Claude Design** is a real Anthropic Labs product (research preview 2026-04-17).
- **GPT-6 Astra/Sol/Luna are real** (Sept 3 and Sept 22, 2026). Opus 5 / 5.5 are real.

**Hype or wrong**

- **"13,000 Automaton agents in 24 hours"**: not in the README, not in any coverage (Decrypt, HackerNoon, DiarioBitcoin). The repo has 7,144 stars and its last commit was 2026-08-26. a16z did lead a Conway Research round (announced 2026-10-02) but for "Underdog", an on-device assistant; Automaton is a crypto-token-adjacent side project (the CONWAY token reportedly pumped 3,600% on the manifesto).
- **"Trillion" is a waitlist**, not software: hellotrillion.ai lists it as free with "open-source on GitHub coming soon"; the waitlist target moved from 5,000 (spoken) to 10,000 (on screen). Nothing to install.
- **"Hancho AI" does not exist.** It is almost certainly Honcho (Plastic Labs), which Hermes integrates. "Hermes Voice" is Hermes' voice mode with pluggable TTS, not a product.
- **Cowork does not create persistent named agents from a prompt.** The official help article says Claude "may coordinate multiple sub-agents" internally; the four-agent "team" is role-play inside one task. Anthropic's own multi-agent post says planner/implementer/tester/reviewer splits are "often counterproductive" and in their experiment "spent more tokens coordinating than doing the work"; multi-agent runs cost 3-10x tokens. "You don't need to review the code" is only true for a throwaway waitlist page.
- **"Runs on Claude Max" is not one claim but three.** Allowed and drawing on the subscription: the unmodified Claude Code CLI/Desktop, `claude -p`, Routines, Desktop scheduled tasks, Projects, GitHub Actions under your own login (support article update 2026-10-07: "Subscription limits still apply to the Claude Agent SDK, claude -p, and third-party apps"; Max/Team plans now also get monthly API credits). Blocked from the subscription and billed to extra usage: third-party harnesses that impersonate Claude Code with a borrowed OAuth token (Hermes "Anthropic OAuth", OpenClaw), enforced since 2026-04-04, "without prior notice". Never allowed: shipping a product where customers log in with Claude.ai or where Haji's Max plan serves them.
- **Multi-model councils for code**: the only 2026 evidence is a non-peer-reviewed preprint and a survey abstract. Anthropic ships the useful part natively (`/deep-research` votes on claims; dynamic workflows can "draft a plan from several angles"; Managed Agents and the Messages API have an advisor model). "Grok 4.7" and "GPT 6.1" from the on-call video could not be verified as shipped models.
- **Jev's "100% task confidence" on screen** is exactly the uncalibrated number you should not route on; Haiku 5.5 ($0.10/$0.50 per MTok) with structured outputs does the same job without a new vendor at roughly the same end-to-end latency.
- **The Chase AI "Agentic OS"** is a $98/month ($58 annual) Skool community; the system is tiered routing plus a markdown vault plus a HUD. The first two are an afternoon's work; the HUD is cosmetic.

## How we should approach this in our own apps and workflow (concrete, ordered, with tradeoffs)

Ordering principle: Haji's constraint is review time, not agent count. Everything below adds a check or removes a chore; nothing adds a dashboard.

1. **Adopt the WWWHH report schema in every subagent (15 minutes, USE NOW).** Append to each `.claude/agents/*.md`: final report must be WHY / NEXT / WHERE (absolute paths only) / HEADS UP / CONFIDENCE 0-100. Orchestrator rule: below 70, spawn a read-only verifier instead of passing on. In dynamic workflows, encode it as `agent(prompt, { schema: { required: ['why','next','paths','heads_up','confidence'] } })`. Tradeoff: confidence is self-reported and uncalibrated; use it to triage, never to approve.

2. **Build the on-call loop on Routines, review-required first (one evening, USE NOW).** PostHog error-tracking webhook -> routine API trigger -> prompt that forces a failing test before any fix, runs the suite and the verify skill, opens a draft PR with a `RISK: small|large` line. Second routine on `pull_request.opened` (filter title starts with `fix:`) runs the code-review skill and labels `safe-to-merge`. Only after ~20 clean PRs, allow auto-merge for `safe-to-merge` + `RISK: small` via a GitHub ruleset. Tradeoffs: routines run with no permission prompts and every included connector's write tools, so strip connectors per routine; the bearer token is a secret; never send production rows, only redacted traces; hourly caps (30 fires per routine) mean an error storm should be throttled at PostHog (spike alerts) rather than in the routine.

3. **Extend the morning brief instead of building a Jarvis (one hour, USE NOW).** Connect Stripe and Zernio (free for two accounts) at claude.ai/customize/connectors, extend the existing `/morning` routine to pull yesterday's revenue, reach, and unread-needing-reply, write `vault/daily/YYYY-MM-DD.md`, and list any feature request two or more users mention. Feed repeated requests into a Claude Code Project as threads. Skip voice, HUD and Meta Ads until ad spend restarts. Tradeoff: keep Gmail read-only in that routine; never auto-reply to customers from a background run.

4. **Stay inside the Max rules (USE NOW).** Personal automations live on native surfaces under Haji's login. Anything that ships to customers uses an API key (Agent SDK on his infra, or Managed Agents with a session budget). Do not install any harness that "reuses Claude Code credentials". Turn on usage credits at claude.ai/settings/usage so a routine does not silently stop mid-month, and watch the weekly limit: background builds compete with the interactive session Haji needs to ship.

5. **Read 12-factor agents once (30 minutes, USE NOW)** and put one line per factor into the CLAUDE.md of any app that embeds an agent loop. Factor 7 (contact humans through tool calls) is the design for every approval gate above; factor 10 (small focused agents) is the argument against every org chart in this batch.

6. **Trial gstack on one feature (TRY THIS WEEK).** Clone to `~/.claude/skills/gstack`, run `./setup`, then `/plan-eng-review` before building, `/qa` after, `/ship` to release, `/retro` at week's end. Keep the 3-4 skills that beat the existing council-gate / code-review / session-learning skills, delete the rest (23 skill descriptions eat context budget; Claude Code warns at 15k tokens of subagent descriptions). Skip `/design` unless an OpenAI key is already in play. Tradeoff: nobody has measured the token cost of the full role chain; run it on a small feature first.

7. **Tiered routing + one markdown vault (one hour, TRY THIS WEEK).** `vault/{daily,reports,receipts}/` in the ops repo; every scheduled task and routine writes there with a dated filename; a `lookup` subagent on Haiku (`model: haiku`, tools Read/Grep) answers "what are my priorities / summarise X" so Opus/Fable is reserved for real work. This is the Agentic OS without the $98/month or the HUD. Tradeoff: add a retention rule and never let a routine write secrets to markdown.

8. **Use Projects as the "AI company" (TRY THIS WEEK, if rolled out).** One project per app, instructions "always open a PR, propose threads before starting, max two threads", thread model Sonnet for routine work. This is the spec-approval gate from ethanplusai's dashboard and the Overview pane Paperclip sells, run by Anthropic with PRs as the unit of review. Tradeoff: Opus at high effort by default burns limits fast; only GitHub.com repos with the Claude GitHub App.

9. **Use dynamic workflows for the few decisions that deserve a council (TRY THIS WEEK).** `/deep-research` for market questions; a saved `/pr-audit` workflow that reviews every changed file and adversarially verifies findings; `/config workflowSizeGuideline=small`; leave ultracode off. For code, one Claude implementer plus one read-only reviewer on a different model is what the evidence supports, not three vendors.

10. **Keep Claude Design for landing pages, decks and onboarding mockups that hand off to Claude Code**, not for a Jarvis HUD.

**Do not do**: Paperclip (org-chart theatre, headless Claude with permissions off, Projects does the useful part), Automaton (wallet + shell + self-modifying code = Haji's liability), Hermes on a VPS (second harness, CVEs, ToS-gray auth; revisit only if a Telegram/WhatsApp front door becomes a real requirement), the Cowork four-role team (keep only a verifier subagent), phone-calling agents, Chase AI+, Jev or the Decisions API before a Haiku structured-output router is measured, OpenHands, agent teams except for a one-off "five competing hypotheses" debugging session.

## Gaps: things they talk about that Haji has not liked yet but should look at

- **Claude Code Routines' API and GitHub triggers** (research preview). None of the videos mention them, yet they are the native form of Paperclip heartbeats, Cursor automations and Hermes-on-a-VPS. Doc: code.claude.com/docs/en/routines.
- **Claude Code Projects** (public beta, Pro/Max, gradual rollout; waitlist at claude.com/form/projects). The coordinator-plus-threads model is what every Jarvis dashboard is imitating.
- **Dynamic workflows and `/deep-research`**, with `schema` on `agent()` as the enforcement point for handoff formats and adversarial verification phases as the native council.
- **Managed Agents** (beta): dollar-capped sessions ($0.08/session-hour plus tokens), scheduled deployments, vault credentials, advisor model, 25 child threads. The legitimate home for "an agent with a budget on a heartbeat" if Haji ever ships one to customers. `/claude-api managed-agents-onboard` in Claude Code walks through it.
- **The subscription vs API credit split**: the 2026-10-07 support update says Max/Team plans now include monthly API credits covering the Agent SDK, `claude -p`, the API and Managed Agents. Amounts were not retrievable this session; worth reading at support.claude.com article 15036540 before deciding where background work runs.
- **Anthropic's "Building multi-agent systems: when and how to use them"** post: context-centric splits, blackbox verifiers with concrete criteria, the "early victory" problem, 3-10x token cost. It is the counter-argument to half this batch and should be the reference whenever a creator sells a team.
- **PostHog error-tracking alerts** (HTTP webhook on new/reopened/spike) as the cheapest trigger for item 2; the free plan allows two alerts.
- **Claude Code agent teams** (experimental, off by default) and **cross-session messaging**: real inter-agent messaging exists natively; it just costs more than the videos admit.
